# 吋讀 Tsundoku

家庭藏書登記與查詢的 PWA。目前是**第五階段**：照片回收桶、借閱管理、AI 認書背、分享圖片到吋讀。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個網站（畫面與程式都在這個檔案裡） |
| `sw.js` | 讓網站能安裝到手機、離線打開 |
| `manifest.webmanifest` | 安裝到手機時的名稱與圖示 |
| `logo-mark.png` | 畫面上用的 logo |
| `icon-192.png`、`icon-512.png`、`icon-maskable-512.png`、`apple-touch-icon.png`、`favicon-64.png` | 手機桌面與瀏覽器分頁的圖示 |
| `firestore.rules` | Firestore 安全規則（要貼到 Firebase 主控台，不會被網站讀取） |

Firebase 設定值**不在**任何檔案裡，是第一次打開網站時貼上、只存在那台裝置。所以 repo 可以公開。

## 第一次設定

### 1. Firebase（在 Tsundoku 專案裡）

1. **建置 → Firestore Database → 建立資料庫**
   - 版本選 Standard
   - 位置選 `asia-east1`（台灣），之後不能改
   - 以「正式版模式」開始
2. **Firestore → 規則**：把 `firestore.rules` 整段貼上，把 `YOUR_EMAIL@gmail.com` 改成你的 Gmail，按「發布」。
3. **建置 → Authentication → 開始使用 → 登入方式 → Google**：啟用，選一個支援電子郵件，儲存。
4. **Authentication → 設定 → 授權網域 → 新增網域**：輸入 `你的帳號.github.io`。
5. **專案設定（齒輪）→ 一般 → 你的應用程式 → 網頁（`</>` 圖示）**：暱稱填 Tsundoku，不用勾 Firebase Hosting，註冊後複製整段 `firebaseConfig`。

### 2. GitHub Pages

1. 打開 Tsundoku repo → **Add file → Upload files**，把這個資料夾裡的所有檔案拖進去 → **Commit changes**。
2. **Settings → Pages → Build and deployment**：Source 選 *Deploy from a branch*，Branch 選 `main` 和 `/ (root)` → **Save**。
3. 等一兩分鐘，網址會是 `https://你的帳號.github.io/Tsundoku/`（大小寫要跟 repo 名稱一樣）。

### 3. 第一次打開

1. 手機用 Chrome 打開網址 → 貼上 `firebaseConfig` → 連接 → 用 Google 帳號登入。
2. Chrome 選單 → **加到主畫面**（或「安裝應用程式」）。
3. 電腦要用的話，同樣貼一次設定、登入一次。

### 4. 開通 Google Books 書目查詢（強烈建議）

沒有金鑰的查詢是全世界共用一份每日額度，常常一早就用完，掃書和書名搜尋都會變成查不到。用 Tsundoku 這個 Firebase 專案開通就會改用你自己的額度，免費。

1. 電腦打開 [Google Cloud 主控台](https://console.cloud.google.com)，上方專案選 **Tsundoku**。
2. 左邊選單 → **API 和服務 → 程式庫**，搜尋 **Books API**，按「啟用」。
3. 回到吋讀：**設定 → 書目查詢 → Google Books → 儲存並測試**，看到「可以了：用的是你自己的額度」就完成。
4. 如果還是說金鑰不能查書目：**API 和服務 → 憑證**，打開「Browser key (auto created by Firebase)」，在「API 限制」把 **Books API** 勾起來，儲存，等幾分鐘再測一次。

### 之後更新網站

把新版的檔案用 **Upload files** 覆蓋上傳即可。repo 裡如果還有舊的 `icon.svg`，可以刪掉，新版已經不用它了。手機上的網站下次打開會自動抓新版；如果沒更新，關掉再開一次。

## 第二階段測試清單

第一次按「掃描」時，Chrome 會問能不能用相機，請選「允許」。如果不小心按了拒絕：網址列左邊的圖示 → 權限 → 相機 → 允許。

- [ ] 從書櫃點一格 → 「登記到這一格」，掃描畫面上方應該顯示那一格和層
- [ ] 掃一本有條碼的書：書名、作者、出版社自動帶入；連掃幾本，確認同一本不會重複跳出
- [ ] 拍版權頁、藏書章：拖四個角校正，按「確定」；版權頁和藏書章存成黑白
- [ ] 「這本沒有條碼」：輸入書名、拍封面，儲存
- [ ] 手動輸入 ISBN（10 碼或 13 碼都可以），也試試打錯一碼，應該會提醒檢查碼不對
- [ ] 手動輸入書名，從搜尋結果選一本
- [ ] 查不到資料的書會標成「待補資料」，之後可以在書籍頁用篩選找出來
- [ ] 再掃一次已登記的書，應該提醒「已經登記過」
- [ ] 書籍頁：搜尋、篩選、打開詳細頁、改閱讀狀態、切換「資料已確認」
- [ ] 編輯：多位作者與角色、半顆星、語言、價格、位置、刪除
- [ ] 斷網登記幾本書，恢復網路後在另一台裝置確認有同步過去
- [ ] 匯出備份，確認照片也在裡面

## 第四階段測試清單（0.4.0）

第三階段的封面牆、搜尋、篩選、排序、類型樹已經在 0.2.x 做完，所以直接進第四階段：補資料。

### 開通 AI 讀圖（Gemini）

1. 打開 [Google AI Studio](https://aistudio.google.com)，用 Google 帳號登入。
2. 按「Get API key」→「Create API key」建立金鑰。
3. 吋讀：**設定 → AI 讀圖 → Gemini 金鑰**，貼上後按「儲存並測試」。金鑰只存在那台裝置，手機和電腦要各貼一次。

### 測試

- [ ] 編輯頁點照片會開大圖，可以放大、拖著看；「刪除」在大圖裡面
- [ ] 大圖按「邊看邊填」，照片會釘在編輯頁上方，往下捲也看得到
- [ ] 掃描時多了「封底文案」照片；編輯頁可以拍版權頁、藏書章、封底文案
- [ ] 摘要旁的「AI 讀封底文案」：讀出來先給你改，再放進摘要
- [ ] 「AI 讀版權頁」：列出讀到的欄位，原本空著的先勾好，勾完按「填進去」
- [ ] 「上網找封面」：開 Google 圖片或博客來，長按圖片 →「複製圖片」，回來按「貼上圖片」→ 確定 → 裁切
- [ ] 也可以長按圖片選「下載圖片」，再按「從相簿選」

## 資料存放位置

所有資料都在 Firestore 的 `users/{你的使用者 ID}/` 底下：

| 集合 | 內容 |
| --- | --- |
| `rooms` | 房間 |
| `cabinets` | 書櫃（列數、欄數、預設深度、編號方向、關掉的格子、高格、個別深度） |
| `books` | 書籍（欄位規格見 `index.html` 裡的 `newBook`） |
| `photos` | 版權頁與藏書章照片（封面直接存在書籍裡） |
| `categories` | 分類樹（第三階段開始寫入） |
| `meta/settings` | 所有者選項、上次備份時間 |
