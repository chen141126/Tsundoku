# 吋讀 Tsundoku

家庭藏書登記與查詢的 PWA。目前是**第六階段**：家人共用書庫，每個人有自己的閱讀紀錄和願望清單，管理者設定權限，刪掉的書先進回收桶。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 整個網站（畫面與程式都在這個檔案裡） |
| `sw.js` | 讓網站能安裝到手機、離線打開 |
| `manifest.webmanifest` | 安裝到手機時的名稱與圖示 |
| `logo-mark.png` | 畫面上用的 logo |
| `icon-192.png`、`icon-512.png`、`icon-maskable-512.png`、`apple-touch-icon.png`、`favicon-64.png` | 手機桌面與瀏覽器分頁的圖示 |
| `firestore.rules` | Firestore 安全規則（要貼到 Firebase 主控台，不會被網站讀取） |

Firebase 設定值**不在**任何檔案裡，是第一次打開網站時貼上、只存在那台裝置。所以 repo 可以公開。

## 第一次設定

### 1. Firebase（在 Tsundoku 專案裡）

1. **建置 → Firestore Database → 建立資料庫**
   - 版本選 Standard
   - 位置選 `asia-east1`（台灣），之後不能改
   - 以「正式版模式」開始
2. **Firestore → 規則**：把 `firestore.rules` 整段貼上，把 `YOUR_EMAIL@gmail.com` 改成你的 Gmail（全部小寫），按「發布」。登入吋讀後，也可以到「設定 › 家人與權限 › 更新資料庫規則」複製已經填好 Gmail 的版本。
3. **建置 → Authentication → 開始使用 → 登入方式 → Google**：啟用，選一個支援電子郵件，儲存。
4. **Authentication → 設定 → 授權網域 → 新增網域**：輸入 `你的帳號.github.io`。
5. **專案設定（齒輪）→ 一般 → 你的應用程式 → 網頁（`</>` 圖示）**：暱稱填 Tsundoku，不用勾 Firebase Hosting，註冊後複製整段 `firebaseConfig`。

### 2. GitHub Pages

1. 打開 Tsundoku repo → **Add file → Upload files**，把這個資料夾裡的所有檔案拖進去 → **Commit changes**。
2. **Settings → Pages → Build and deployment**：Source 選 *Deploy from a branch*，Branch 選 `main` 和 `/ (root)` → **Save**。
3. 等一兩分鐘，網址會是 `https://你的帳號.github.io/Tsundoku/`（大小寫要跟 repo 名稱一樣）。

### 3. 第一次打開

1. 手機用 Chrome 打開網址 → 貼上 `firebaseConfig` → 連接 → 用 Google 帳號登入。
2. Chrome 選單 → **加到主畫面**（或「安裝應用程式」）。
3. 電腦要用的話，同樣貼一次設定、登入一次。

### 4. 開通 Google Books 書目查詢（強烈建議）

沒有金鑰的查詢是全世界共用一份每日額度，常常一早就用完，掃書和書名搜尋都會變成查不到。用 Tsundoku 這個 Firebase 專案開通就會改用你自己的額度，免費。

1. 電腦打開 [Google Cloud 主控台](https://console.cloud.google.com)，上方專案選 **Tsundoku**。
2. 左邊選單 → **API 和服務 → 程式庫**，搜尋 **Books API**，按「啟用」。
3. 回到吋讀：**設定 → 書目查詢 → Google Books → 儲存並測試**，看到「可以了：用的是你自己的額度」就完成。
4. 如果還是說金鑰不能查書目：**API 和服務 → 憑證**，打開「Browser key (auto created by Firebase)」，在「API 限制」把 **Books API** 勾起來，儲存，等幾分鐘再測一次。

### 之後更新網站

把新版的檔案用 **Upload files** 覆蓋上傳即可。repo 裡如果還有舊的 `icon.svg`，可以刪掉，新版已經不用它了。手機上的網站下次打開會自動抓新版；如果沒更新，關掉再開一次。

## 第六階段：家人共用（0.6.0）

### 升級步驟（只要做一次）

1. 上傳 `index.html`、`sw.js`、`firestore.rules`、`README.md` 到 GitHub。
2. 你自己先打開吋讀。第一次會顯示「正在把資料升級成家人共用格式」：書上的閱讀狀態、評分、最愛、心得和願望清單，會搬到你自己名下。升級前建議先匯出一份完整備份。
3. **設定 › 家人與權限 › 更新資料庫規則**：按「複製規則」，到 Firebase 主控台 › Firestore › 規則，全部刪掉、貼上、按「發布」。沒做這步，家人登入會被擋。
4. **設定 › 家人與權限 › 新增家人**：輸入家人的 Gmail、稱呼，選「只能檢視」或「可修改」。加好會跳出邀請 QR code 和連結。
5. 家人用手機掃 QR code（或打開你傳的連結）→「接受邀請」→ 用**他自己的** Google 帳號登入。

### 三種身分

| | 管理者（你） | 可修改 | 只能檢視 |
| --- | --- | --- | --- |
| 看所有的書 | ✓ | ✓ | ✓ |
| 自己的閱讀狀態、評分、最愛、心得、願望清單 | ✓ | ✓ | ✓ |
| 新增、修改書，登記借閱，改書櫃 | ✓ | ✓ | |
| 刪書（進回收桶）、從回收桶還原 | ✓ | ✓ | |
| 永久刪除、刪房間／書櫃／類型、照片自動清除 | ✓ | | |
| 加家人、改權限、從備份還原 | ✓ | | |

權限寫在 Firebase 的規則裡，不只是畫面上把按鈕藏起來。

### 測試清單

- [ ] 示範模式：設定 › 試用身分，切換「可修改」「只能檢視」，看畫面和權限對不對；每個身分的閱讀紀錄互不影響

## 0.6.1：初心者和隱私書籍

0.6.0 還沒用過的話，直接照上面的升級步驟做就好（規則只要更新一次，用這一版的）。已經更新過 0.6.0 規則的話，要**再更新一次**資料庫規則。

- **初心者**：設定 › 家人與權限 › 點家人 › 打開「初心者」（綠色小芽）。初心者看不到「限制級」的書；限制級的書在資料庫那層就擋掉，不會傳到他的裝置上。
- **限制級**：編輯頁「擁有狀態」下面，和「隱私」同一行。初心者自己看不到這個開關。
- **隱私**：打開後，這本書只在你自己的書庫裡，其他人（包括管理者）都看不到，照片也一起搬過去；關掉就放回家裡的書。只能檢視的人自己加的書（不是願望清單）一定是隱私。
- 隱私書籍丟進回收桶後，本人可以還原；永久刪除還是只有管理者能做，但管理者只看得到「某某的隱私書籍」，看不到書名。
- 管理者的完整備份不包含別人的隱私書籍；每個人自己匯出的備份才有。

### 測試清單

- [ ] 編輯頁「限制級」「隱私」在同一行
- [ ] 示範模式：把「家人（只能檢視）」設成初心者，切換成他，限制級的書不見了，也沒有限制級開關
- [ ] 用「可修改」的身分把一本書設成隱私：切回管理者看不到；回收桶裡只顯示「…的隱私書籍」，可以永久刪除
- [ ] 隱私書籍取消隱私：回到家裡的書，大家都看得到
- [ ] 只能檢視的人新增書，選「已收藏」：自動變成隱私

## 0.6.2：小圈圈

已經更新過資料庫規則的話，這版要**再更新一次**（設定 › 家人與權限 › 更新資料庫規則）。

- **建立**：設定 › 小圈圈 › 新增小圈圈，取名字、勾選要邀請的家人；也可以先不邀請，自己一個人用。家人要先登入吋讀一次，才會出現在名單上。如果已經有成員一樣的小圈圈，會提醒你是哪一個，確定之後還是可以再建一個。
- **邀請**：被邀請的人會在書架頁和設定看到邀請，按「接受」才會加入。圈裡的人都能再邀請別人、取消還沒接受的邀請、改名。
- **大家平等**：圈裡的人（包括「只能檢視」的人）都能新增、修改圈裡的書。要把家裡的書放進小圈圈，或把圈裡的書公開，還是要有修改權限。
- **選誰看得到**：有小圈圈之後，編輯頁的「隱私」會變成選單：公開／只有我／小圈圈「…」。
- **管理者看不到**小圈圈和裡面的書；回收桶裡只顯示「小圈圈「名字」的書」，可以永久刪除。
- **退出**：先把自己放進來的書處理完（勾選 → 留在圈裡／公開／鎖隱私／丟掉），清單清空後確認。最後一個人退出時，要處理圈裡所有的書，退出後小圈圈就解散；選「丟掉」的書會進自己的回收桶，還能還原。
- 解散的小圈圈如果還留著書（例如初心者看不到的限制級書），管理者的回收桶會顯示「小圈圈「名字」解散後留下的書」，可以永久刪除。

### 測試清單

- [ ] 示範模式：用「可修改」建立小圈圈邀請「只能檢視」；切換過去按接受；兩邊都看得到圈裡的書，管理者看不到
- [ ] 小圈圈可以只有自己一個人
- [ ] 建立（或邀請後）成員跟現有的小圈圈一樣：會提醒名字，按確定還是能建
- [ ] 圈裡的書丟進回收桶：圈裡的人可以還原；管理者看到圈名、看不到書名
- [ ] 退出小圈圈：逐本處理（留在圈裡、公開、鎖隱私、丟掉），清單清空後確認
- [ ] 最後一個人退出：沒有「留在圈裡」，退出後小圈圈解散

### 0.6.3 修改

- [ ] 小圈圈可以只有自己一個人
- [ ] 成員一樣的小圈圈不再擋，改成提醒「已經有相同成員的小圈圈「…」，確定要再新增一個嗎？」

## 資料存放位置

所有資料都在 Firestore 的 `users/{管理者的使用者 ID}/` 底下：

| 集合 | 內容 |
| --- | --- |
| `rooms` | 房間 |
| `cabinets` | 書櫃（列數、欄數、預設深度、編號方向、關掉的格子、高格、個別深度） |
| `books` | 書籍（全家共用的資料；`adult` 限制級；`deletedAt` 有值代表在回收桶裡） |
| `photos` | 版權頁與藏書章照片（封面直接存在書籍裡） |
| `categories` | 分類樹 |
| `meta/settings` | 所有者選項、出版商、上次備份時間、回收桶設定 |
| `members/{email}` | 家人名單：稱呼、權限（`editor` 可修改、`viewer` 只能檢視）、`minor` 初心者、最後上線時間 |
| `people/{使用者 ID}/reading/{書 ID}` | 每個人自己的閱讀狀態、讀到第幾頁、日期、評分、最愛、心得 |
| `people/{使用者 ID}/wishlist/{書 ID}` | 每個人自己的願望清單 |
| `people/{使用者 ID}/private/{書 ID}` | 隱私書籍（只有本人讀得到，管理者也不行） |
| `people/{使用者 ID}/privatePhotos/{照片 ID}` | 隱私書籍和願望清單的照片 |
| `people/{使用者 ID}/privateBin/{書 ID}` | 隱私書籍的回收桶紀錄（沒有書名，管理者靠它永久刪除） |
| `circles/{圈 ID}` | 小圈圈：名字、成員、邀請中的人；`circles/{圈 ID}/books`、`photos` 是圈裡的書和照片 |
| `circleBin/{圈 ID}__{書 ID}` | 小圈圈書的回收桶紀錄（有圈名、沒有書名） |
| `directory/{使用者 ID}` | 家人名冊（稱呼），拉小圈圈用 |
| `moves/{書 ID}` | 書搬到小圈圈的記號（規則用來確認書是搬家，不是被刪掉） |
